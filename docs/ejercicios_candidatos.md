# Candidatos a casos de prueba

Son propuestas basadas en ejemplos desarrollados de las fuentes. **No se
declaran correctas**: el resultado debe verificarse manualmente antes de
convertirlos en pruebas.

1. **Conjunto por propiedad.** Evaluar el conjunto definido por cubos de los
   elementos de `{0,1,2}` y comprobar la enumeración resultante. Fuente:
   `Conjuntos.pdf`, p. 1, ejemplo 2.
2. **Conjunto potencia.** Calcular `P({0,1})` y su cardinalidad. Fuente:
   `Conjuntos.pdf`, p. 2, ejemplo 6.
3. **Inclusión-exclusión.** Con 35 votantes, 14 que apoyan el referendo 1 y
   26 el referendo 2, calcular la intersección. Fuente: `Conjuntos.pdf`, p. 10,
   ejemplo 40.
4. **Propiedades de una relación.** Para `≤` sobre `N`, verificar
   reflexividad, transitividad, antisimetría y no simetría. Fuente:
   `Relaciones.pdf`, p. 2, ejemplo 6.
5. **Cerradura de relación.** Para la relación de `Relaciones.pdf`, p. 3,
   ejemplo 9, comprobar qué pares faltan para las propiedades elegidas.
   El PDF no entrega aquí la cerradura final, por lo que el resultado debe
   calcularse y verificarse.
6. **Dependencia parcial.** En la venta con clave `(venta_no,cod_prod)`,
   comprobar que `cod_prod→nombre_prod` impide 2FN. Fuente:
   `BD1_MER_Normalizacion_Vr20250311.pdf`, pp. 17--20.
7. **Dependencia transitiva.** Comprobar la cadena
   `código→programa`, `programa→valor_semestre`,
   `código→valor_semestre` y el diagnóstico de 3FN. Fuente:
   `BD1_MER_Normalizacion_Vr20250311.pdf`, pp. 24--26.
8. **Consulta relacional.** Sobre una tabla municipal, aplicar el filtro
   `pob1991>20000` y comprobar las columnas y tuplas devueltas. Fuente:
   `Bases de datos relacionales.pdf`, p. 3.
