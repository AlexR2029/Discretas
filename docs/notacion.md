# Notación observada en los PDFs

## Conjuntos

| Símbolo o forma | Nombre/uso |
|---|---|
| `A, B, S, T` | conjuntos |
| `x ∈ A` | pertenencia |
| `A ⊆ B` / `A ⊂ B` | subconjunto / subconjunto propio |
| `∅` | conjunto vacío |
| `P(S)` o `℘(S)` | conjunto potencia |
| `A ∪ B` | unión |
| `A ∩ B` | intersección |
| `A'` | complemento respecto del universo |
| `A − B` | diferencia |
| `A × B` | producto cartesiano |
| `|A|` | cardinalidad |
| `ℕ, ℤ, ℚ, ℝ, ℂ` | naturales, enteros, racionales, reales y complejos |
| `∀`, `∃` | para todo, existe |

## Relaciones y funciones

| Símbolo o forma | Nombre/uso |
|---|---|
| `ρ` | relación |
| `(x,y)` | par ordenado |
| `x ρ y` | `x` se relaciona con `y` |
| `ρ⁻¹` | relación inversa |
| `ρ*` | cerradura de una relación |
| `f:S→T` | función de dominio `S` a codominio `T` |
| `f(s)` | imagen de `s` |
| `g∘f` | composición |
| `i_S` | función identidad |
| `f⁻¹` | función inversa |
| `≤`, `≼`, `≺` | relación de orden, orden parcial y orden estricto |
| `[x]` | clase de equivalencia de `x` |

## Bases de datos y normalización

| Símbolo o forma | Nombre/uso observado |
|---|---|
| `A → B` | dependencia funcional, usada en el PDF de normalización |
| `PK` | clave principal |
| `1FN`, `2FN`, `3FN` | primera, segunda y tercera forma normal |
| `CREATE TABLE`, `INSERT`, `DELETE`, `UPDATE`, `SELECT` | comandos SQL |
| `FROM`, `WHERE` | origen y filtro de una consulta SQL |
| `AVG`, `STDDEV`, `SUM`, `MAX` | funciones agregadas SQL |
| `JOIN` / `BCNF` | **no aparecen en los PDFs** |

La extracción de los PDFs presenta algunos símbolos con espaciado o
codificación irregular; la tabla normaliza solo su escritura, no añade
notación que no esté respaldada.
